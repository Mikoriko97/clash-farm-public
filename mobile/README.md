# Clash Farm — Android app (Solana dApp Store)

The game in a WebView shell generated by the Solana Mobile CLI (`solana-mobile webshell`, ADR-042): it opens the
game's URL full screen, landscape only, and hands Solana wallet intents (Mobile Wallet Adapter) to the wallet app on
the phone — the Seeker's own wallet, Phantom, Solflare. All game code stays on the web; this project holds no logic.

## Configuration (`gradle.properties`)

- `SOLANA_MOBILE_URL` — the page the app opens.
- `SOLANA_MOBILE_APPLICATION_ID` — the store id; permanent once published.
- `SOLANA_MOBILE_VERSION_CODE` / `SOLANA_MOBILE_VERSION_NAME` — bump the code for every release.

The Kotlin namespace (`online.clashofstaking.app`) matches the application id (`SOLANA_MOBILE_APPLICATION_ID`, fixed for good: the dApp Store treats another id as another app).

## Changes against the generated template

- `AndroidManifest.xml`: `screenOrientation="sensorLandscape"`.
- `MainActivity.kt`: system bars hidden (immersive), only the camera cut-out kept clear; no pull-to-refresh (a
  downward drag turns the camera); no page zoom (two fingers belong to the joystick and the camera).
- Launcher icon: `client/icon.svg` as an adaptive vector (`res/drawable/ic_launcher_*.xml`).

## Build

```bash
read -rs -p "keystore password: " SOLANA_MOBILE_KEYSTORE_PASSWORD; echo; export SOLANA_MOBILE_KEYSTORE_PASSWORD
export SOLANA_MOBILE_KEY_PASSWORD="$SOLANA_MOBILE_KEYSTORE_PASSWORD"
CF_APK_KEYSTORE=/secure/place/clashfarm.keystore bash mobile/build-apk.sh
```

Gradle checks every dependency against `gradle/verification-metadata.xml` (sha256); after a version change regenerate
it with `./gradlew --write-verification-metadata sha256 assembleRelease` and review the diff.

Prints the signing certificate and the APK's SHA-256. Install on a phone: `adb install -r mobile/app/build/outputs/apk/release/app-release.apk`.
The release keystore is created and kept by the owner, outside the repo, with a backup: every dApp Store update must
be signed with the same key (`docs/RUNBOOK.md`, «APK і dApp Store»).
